Features

Everything lives inside the launcher — no third-party tools, no copying files by hand.

Instances

Separate installs with their own mods, worlds and settings. Custom icons, groups, cloning and one-file export.

Content catalog

Mods, resource packs, shaders, data packs and addons from Modrinth and CurseForge — search and install straight into the instance you need.

Modpacks

Install a whole pack from the catalog in one click. A downloaded .mrpack or CurseForge zip imports from file too.

Local server

The core downloads itself, and the server runs with a live console, a server.properties editor, and its own plugin catalog.

Server list

Ping, player count and MOTD, right inside the launcher — without opening the game.

Accounts and themes

Multiple accounts with Ctrl+1…9 switching, and 17 themes that apply instantly without a restart.

Frequently asked questions

The short version.

What is Legism?

An independent, hobbyist fork of Legacy Launcher, a Minecraft launcher. Ads and telemetry are cut out, and a built-in mod catalog, modpacks and local servers are added in their place. The project used to be called "Legacy by tgsko".

Do I need a Minecraft license?

Minecraft is a paid game, and the launcher doesn't distribute or grant it. Legism only launches the game and manages instances.

Is it safe?

The source is fully open — you can read it and build it yourself. Only download it from the GitHub releases page: builds from other sites are unverified.

What's the difference between the installer and the portable version?

The installer sets the launcher up like a regular program, with shortcuts. The portable version unpacks into any folder and doesn't touch the system — handy to keep on a flash drive or move between drives along with your instances.

What Windows version do I need?

Windows 10 or 11, 64-bit. Java ships with it — nothing else to install separately.

Do I need my own CurseForge key?

No. A key is already built in, so the CurseForge catalog works right away. You can set your own in settings if you want to — it replaces the built-in one.

Where do I report bugs?

On GitHub Issues, or in our chats. Please don't report problems with this fork to the Legacy Launcher team — they have nothing to do with it.

Community & Support

We have a Telegram and a Discord where other users can help you. You can also open an issue on GitHub if you want to report a bug or suggest a new feature.
